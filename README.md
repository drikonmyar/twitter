Functionalities:

1. New users can sign up to access the home page for the first time
2. Already existing users can directly login using correct credentials
3. In home page, user will see the account information and all tweets tweeted by the user and other users
4. Once user will tweet, the new tweet will be appended at the bottom of the tweet screen with date and time
5. User can logout from the home page, once logged out user has to login again to view the home page
